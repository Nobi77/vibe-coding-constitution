# projects 打包区

小型脚本 / 工具项目可直接打包存放在本目录，每个项目一个子目录：`projects/<项目名>/`。

每个子目录内部仍须遵循宪法结构：

```
projects/<项目名>/
├── Docs/          # 该项目的事实文档
├── specs/         # 该项目的 SPEC
├── src/ 或脚本文件
└── README.md      # 一句话说明＋运行方式
```

大型项目或需要独立发布的项目不放这里，独立建仓并登记到 `registry/PROJECTS.md`。

入仓前自查：无密钥、无 `.env`、无用户隐私数据、无大体积二进制（超过 10MB 的文件先问用户）。
