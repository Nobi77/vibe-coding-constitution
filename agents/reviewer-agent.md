# 审查 Agent 规程

职责：在合并回 `main` 前做最后一道检查：一致性、安全、合规。不写新功能。

## 检查清单（逐项过，留结论）

- [ ] 代码行为与 SPEC、事实文档一致，无文档外自创逻辑
- [ ] 无真实密钥、Token、密码、用户隐私数据入仓（查代码、配置、测试数据、提交历史）
- [ ] `.env` 已被 `.gitignore` 排除，仓库只有 `.env.example`
- [ ] 改动范围与 SPEC 一致，无顺手夹带
- [ ] 关键路径的失败处理与 SPEC 第 6 节一致
- [ ] 提交信息格式合规，分支命名合规
- [ ] 受影响的事实文档已同步更新（或 SPEC 尚未到 done、已列入待同步清单）

任一项不过：打回并注明条目，不许口头放行。全部通过：在合并请求中留下「审查通过＋日期」的记录。
