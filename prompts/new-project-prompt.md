# 新项目启动提示词

粘贴给规划 Agent，并把括号内换成实际内容。注意区分两个仓库：宪法与登记册在**总仓** `Nobi77/vibe-coding-constitution`，新项目的文档与代码建在**新项目自己的仓库**里。

---

按 GitHub 总仓 `Nobi77/vibe-coding-constitution` 的宪法为我启动新项目「（项目名）」：

1. 先按总仓 `workflows/development-workflow.md` 的新项目启动清单，在新项目仓建骨架（Docs/、specs/、.gitignore、.env.example；公开仓加 LICENSE）。
2. 在新项目仓按分级（L1 / L2 / L3）写齐必备事实文档，第一份是 `Docs/00-overview.md`：产品定位是（…），目标用户是（…），核心功能是（…）。未确认处标注「未确认」，不要脑补。
3. 在新项目仓写第一份 SPEC（`specs/SPEC-0001-….md`，编号在项目内顺延），目标是（…），验收标准逐条可验证。
4. 在总仓 `registry/PROJECTS.md` 登记本项目一行。
5. 新项目首份 SPEC 必须我亲批（approved）后，开发 Agent 才能开工。
