# 新项目启动提示词

粘贴给规划 Agent，并把括号内换成实际内容：

---

按 GitHub 仓库 `Nobi77/vibe-coding-constitution` 的宪法为我启动新项目「（项目名）」：

1. 先按 `workflows/development-workflow.md` 的新项目启动清单建仓与目录骨架。
2. 写第一份事实文档 `Docs/00-overview.md`：产品定位是（…），目标用户是（…），核心功能是（…）。未确认处标注「未确认」，不要脑补。
3. 写第一份 SPEC（`specs/SPEC-0001-….md`），目标是（…），验收标准逐条可验证。
4. 在总仓 `registry/PROJECTS.md` 登记本项目一行。
5. SPEC 写好后先给我看，我批准（approved）后再让开发 Agent 开工。
